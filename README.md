# Lauf-Cockpit

Persönliche Trainings-App für den Halbmarathon. Installierbare Web-App (PWA), läuft offline.

- **Daten** liegen nur auf dem Gerät (localStorage). Nichts davon ist in diesem Repo.
- **Von Claude einfügen:** Import-Codes (`LC1.…`) aus dem Chat übernehmen, auch als Link `#import=LC1.…`.
- **Woche an Claude:** Zusammenfassung der aktuellen und der Vorwoche in die Zwischenablage.
- **Backup:** Export und Import als JSON-Datei.

Dateien: `index.html`, `app.css`, `app.js`, `sw.js` (Offline-Cache), `manifest.webmanifest`, `icons/`.
